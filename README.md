# Personal Portfolio Website

A simple and professional personal portfolio website created using **HTML and CSS**. This portfolio showcases my introduction, skills, projects, and contact information.

## 🚀 Features

* Clean and simple design
* Responsive layout for mobile and desktop
* Navigation menu
* About Me section
* Skills section
* Projects section
* Contact section
* Social media links
* Smooth scrolling

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📂 Project Structure

```text
portfolio/
│
├── index.html
├── style.css
└── README.md
```

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. The portfolio website will open.

## ✏️ Customization

You can customize the following details in `index.html`:

* Your name
* About Me information
* Skills
* Projects
* Email address
* Phone number
* LinkedIn profile
* GitHub profile

You can also modify `style.css` to change:

* Colors
* Fonts
* Spacing
* Layout
* Button styles

## 📌 Purpose

This project was created to practice basic web development concepts and to create a personal portfolio for showcasing my skills and projects.
